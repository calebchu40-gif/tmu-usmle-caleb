血小板紊乱 Platelet Disorders

Note #5 ｜ 点击箭头逐级展开 ｜ 点击配图可放大 ｜ 配图均为讲义原图（含病理图与临床照片）
  • 一、病理生理分型
    • 总论与分型
      • ›〔一〕生成减少 ↓Platelet Production：骨髓低增生或高增生 → 三系生成↓ → 全血细胞减少（pancytopenia）
      • ›〔二〕破坏增多 ↑Platelet Destruction：免疫型（抗体标记 → 脾清除）或非免疫型（微血栓剪切红细胞 + 消耗血小板）
      • ›〔三〕扣押增多 ↑Platelet Sequestration：脾大 → 红细胞与血小板在脾内蓄积 → 循环血小板↓，且脾进一步增大
      • ›止血三环节（用于理解功能障碍）：黏附 → 活化与颗粒释放 → 聚集
      • ›〔一〕黏附：vWF 或 GpIb-IX 活性↓ → 血小板不能附着于内皮下组织 → 不能形成血栓
      • ›〔二〕聚集：GpIIb/IIIa 活性↓ → 不能通过纤维蛋白原桥互相连接 → 不能形成血栓
      • ›〔三〕颗粒释放：ADP 与 TXA2 释放↓ → 血小板不能彼此聚集 → 不能形成血栓
      • 三者关系：释放出的 ADP 与 TXA2 会上调 GpIIb/IIIa 表达，因此释放缺陷最终也表现为聚集不良
    • 1 生成减少
      • 再生障碍性贫血 Aplastic Anemia
        • ①① 病因：自身免疫性破坏造血干细胞（autoimmune destruction of hematopoietic stem cells）
        • ②② 发病机制：干细胞增殖与分化↓
        • ③③ 病理生理：WBC、血小板、RBC 生成↓ → 全血细胞减少（pancytopenia）
        • ④④ 并发症：贫血（anemia）、出血、感染三联
        • ⑤⑤ 诊断：骨髓活检示低增生（hypocellular）+ 脂肪替代（fatty replacement）→ 涂片无原始细胞
        • ⑥⑥ 治疗：停用可疑药物；环孢素（CsA）+ 抗胸腺细胞球蛋白（ATG）；异基因造血干细胞移植
      • 白血病 Leukemia（AML／ALL）
        • ①① 病因：造血细胞恶性克隆性转化
        • ②② 发病机制：骨髓内原始细胞（blasts）>20%
        • ③③ 病理生理：挤占空间 → 三系生成↓ → 全血细胞减少
        • ④④ 并发症：全血细胞减少（贫血／出血／感染）+ 原始细胞浸润
        • ⑤⑤ 诊断：骨髓活检 >20% blasts；外周血涂片见髓系（myeloid）或淋系（lymphoid）原始细胞
        • ⑥⑥ 治疗：按白血病方案化疗／移植（讲义未展开）
      • 骨髓增生异常综合征 MDS
        • ①① 病因：克隆性造血异常
        • ②② 发病机制：发育异常（dysplastic）细胞↑
        • ③③ 病理生理：不能增殖分化 + 前体细胞凋亡 → 三系↓
        • ④④ 并发症：全血细胞减少，可进展为急性白血病
        • ⑤⑤ 诊断：骨髓高增生 + 发育异常 + blasts <20%；涂片见假性 Pelger-Huët 中性粒细胞（pseudo-Pelger-Huët neutrophils）
        • ⑥⑥ 治疗：支持治疗／去甲基化药物（讲义未展开）
    • 2 破坏增多·免疫
      • 免疫性血小板减少性紫癜 ITP
        • ①① 病因：原发性为特发性（idiopathic，最常见）；继发性：感染（HIV／HCV）、恶性肿瘤（CLL）、自身免疫病（SLE）
        • ②② 发病机制：抗体针对"类糖蛋白"抗原
        • ③③ 病理生理：结合血小板 GpIIb/IIIa → 血小板被标记（tagged）→ 脾内破坏 → 孤立性血小板减少（isolated thrombocytopenia）
        • ④④ 并发症：表浅出血——瘀点／紫癜（petechiae／purpura）、牙龈出血（gingival bleeding）、鼻出血（epistaxis）、月经过多（menorrhagia）；无脾大；例外：Evans 综合征（AIHA + ITP）
        • ⑤⑤ 诊断：排除性诊断（diagnosis of exclusion）——孤立性血小板减少 + 涂片正常 + 凝血正常 + 无相关病史；SLE、HIV／HCV、恶性肿瘤、药物全阴 → 原发性 ITP；任一阳性 → 继发性 ITP
        • ⑥⑥ 治疗：糖皮质激素（corticosteroids）或静脉丙种球蛋白（IVIG）（出血或 <30k）→ 利妥昔单抗（rituximab）或 TPO 受体激动剂（romiplostim／eltrombopag）→ 脾切除（splenectomy，>12 个月）；输血前先给激素或 IVIG
      • 肝素诱导的血小板减少症 HIT
        • ①① 病因：肝素暴露（heparin exposure），约 5–15 天
        • ②② 发病机制：肝素 + PF4（血小板第 4 因子 platelet factor 4）
        • ③③ 病理生理：肝素-PF4 复合物 → 产生抗体 → 结合 FcγRIIa → 血小板活化 → 血小板在血栓形成中被消耗 + 释放促凝物质 → 全身血栓
        • ④④ 并发症：静脉血栓（DVT／PE，最常见）；动脉血栓（AMI／ALI／CVA）；皮肤血栓 → 皮肤坏死（skin necrosis）；实验室：凝血正常 + 血小板快速下降（>5 天）+ 4T 评分↑
        • ⑤⑤ 诊断：PF4 抗体（＋）→ 5-羟色胺释放试验（serotonin release assay）确认
        • ⑥⑥ 治疗：停用肝素 + 替代抗凝——阿加曲班（argatroban）／磺达肝癸钠（fondaparinux）；需长期抗凝者用华法林（warfarin），以前两者桥接 5 天；监测血小板是否改善；有血栓且需长期抗凝者按上法桥接
      • 抗磷脂综合征 APLS
        • ①① 病因：原发性特发性；继发性为自身免疫病如 SLE（最常见）
        • ②② 发病机制：抗磷脂抗体（antiphospholipid antibodies）结合血小板
        • ③③ 病理生理：激活血小板与促凝物质 + 抗凝活性↓（蛋白 C／蛋白 S／抗凝血酶 III）→ 血小板消耗↑ → 血小板↓ + 全身动静脉血栓
        • ④④ 并发症：静脉血栓（DVT／PE，最常见）；动脉血栓（AMI／ALI／CVA）；灾难性 APLS 以广泛动脉血栓为主；胎盘血栓 → 反复流产（10 周前 ≥3 次自发性流产）；实验室：PTT↑（狼疮抗凝物所致）+ 血小板↓
        • ⑤⑤ 诊断：抗磷脂抗体三项 ≥1 项阳性——抗心磷脂抗体（anti-cardiolipin）、狼疮抗凝物（lupus anticoagulant）、抗 β2 糖蛋白（anti-beta 2 glycoprotein）
        • ⑥⑥ 治疗：抗凝（住院用低分子肝素 LMWH → 长期华法林）；灾难性 APLS：血浆置换（PLEX）或 IVIG + 激素（corticosteroids）；妊娠期避免华法林、继续 LMWH；监测血小板改善；妊娠期全程用 LMWH
    • 3 破坏增多·非免疫（TMA）
      • 弥散性血管内凝血 DIC
        • ①① 病因：脓毒症（sepsis）、创伤（trauma）、产科并发症如胎盘早剥（placental abruption）
        • ②② 发病机制：促凝物质激活
        • ③③ 病理生理：血栓形成，消耗凝血蛋白、血小板与纤维蛋白原（fibrinogen）→ 微血栓剪切红细胞 → 凝血病（coagulopathy）+ 血小板↓ + 贫血
        • ④④ 并发症：微血栓 → 器官缺血 → 多器官衰竭（AKI／肝衰竭／ARDS／DVT-PE／脑病）；出血——表浅（瘀点、鼻衄，因血小板↓）+ 深部（关节积血 hemarthrosis、颅内出血 ICH、消化道出血 GIB，因凝血因子↓）；静脉穿刺点渗血（oozing from IV sites，题眼）
        • ⑤⑤ 诊断：MAHA 三联（溶血性贫血 + 血小板减少 + 破碎红细胞）→ 凝血异常：PT／INR↑、PTT↑、D-二聚体（D-dimer）↑、纤维蛋白原↓
        • ⑥⑥ 治疗：治疗原发病（如脓毒症用抗生素）为第一；支持治疗——浓缩红细胞（PRBCs）按血红蛋白阈值、血小板按阈值、新鲜冰冻血浆（FFP）用于 INR>1.6、冷沉淀（cryoprecipitate）用于纤维蛋白原 <100 mg/dL；血常规看红细胞与血小板；用 FFP 时监测 INR；用冷沉淀时监测纤维蛋白原
      • 溶血尿毒综合征 HUS
        • ①① 病因：大肠杆菌 O157:H7（EHEC）类志贺毒素（shiga-like toxin）所致胃肠炎
        • ②② 发病机制：毒素
        • ③③ 病理生理：肾小球内皮功能障碍 + 血小板聚集 → 血栓形成、消耗血小板 → 微血栓剪切红细胞 → AKI + 血小板↓ + 贫血
        • ④④ 并发症：肾小球微血栓 → 急性肾损伤（AKI），发生于腹泻病之后；凝血正常；溶血（破碎红细胞、LDH↑、结合珠蛋白↓）+ 血小板↓
        • ⑤⑤ 诊断：MAHA + 凝血正常 + 腹泻前驱史 + 肾衰竭；ADAMTS13 正常
        • ⑥⑥ 治疗：避免抗生素与止泻药（防毒素大量释放）；严重肾衰时透析（指征：难治性酸中毒／容量负荷过重／高钾／尿毒症并发症）；血常规看红细胞与血小板；监测肾功能以判断是否需要透析及其反应
      • 血栓性血小板减少性紫癜 TTP
        • ①① 病因：ADAMTS13 缺乏（多为获得性）；触发抗体的药物：噻氯匹定（ticlopidine）或氯吡格雷（clopidogrel）、化疗药
        • ②② 发病机制：抗 ADAMTS13 自身抗体
        • ③③ 病理生理：ADAMTS13↓ → vWF 多聚体降解↓ → 多聚体堆积于内皮 → 血小板黏附、被消耗 → 肾与脑微血栓
        • ④④ 并发症：肾小球微血栓 → AKI；脑微血栓 → 神经系统症状（意识改变 AMS／卒中／抽搐）
        • ⑤⑤ 诊断：MAHA + 凝血正常 + ADAMTS13↓
        • ⑥⑥ 治疗：血浆置换（PLEX）+ 激素为一线；难治者加利妥昔单抗；禁止输注血小板；监测血常规中红细胞与血小板的改善
    • 4 扣押
      • 脾扣押 Splenic Sequestration
        • ①① 病因：门脉高压（portal hypertension）→ 肝硬化（cirrhosis）
        • ②② 发病机制：静脉血反流进脾
        • ③③ 病理生理：脾大（splenomegaly）→ 脾清除红细胞与血小板↑（脾功能亢进 hypersplenism）→ 脾大 + 贫血 + 血小板↓
        • ④④ 并发症：脾大 + 两系减少；病程缓慢
        • ⑤⑤ 诊断：脾大 + 肝硬化／门脉高压 + 涂片正常 + 凝血正常
        • ⑥⑥ 治疗：针对门脉高压与原发病（讲义未展开）；镰状细胞病（SCD）脾隔离危象（splenic sequestration crisis）→ 血小板与血红蛋白快速下降
    • 5 功能障碍·黏附
      • 血管性血友病 vWD
        • ①① 病因：遗传性；1 型约 85%（常染色体显性 AD）、2 型约 15%（AD，功能异常）、3 型罕见（常染色体隐性 AR，完全缺失）
        • ②② 发病机制：vWF 数量或质量异常
        • ③③ 病理生理：血小板不能黏附于内皮下胶原 → 不能形成血栓；vWF 同时携带因子 VIII → FVIII↓
        • ④④ 并发症：黏膜出血（鼻衄／牙龈出血／月经过多）、出血家族史；PTT 可延长（FVIII↓）
        • ⑤⑤ 诊断：瑞斯托霉素辅因子试验不聚集 + 加富含 vWF 血浆后聚集恢复；vWF 抗原（vWF antigen）+ 因子 VIII↓
        • ⑥⑥ 治疗：轻度用去氨加压素（DDAVP）；中重度用 vWF 浓缩物；两者不可得时用冷沉淀；观察出血是否停止；治疗后查 vWF 活性（瑞斯托霉素辅因子试验）与因子 VIII 以确认疗效
      • 伯纳德-苏利耶综合征 BSS
        • ①① 病因：常染色体隐性（AR）遗传
        • ②② 发病机制：GpIb-IX 缺失
        • ③③ 病理生理：血小板不能结合 vWF → 黏附失败；伴巨大血小板（large platelets）与血小板减少
        • ④④ 并发症：黏膜出血、巨大血小板、血小板减少
        • ⑤⑤ 诊断：瑞斯托霉素不聚集且加血浆不能恢复；流式细胞术 GpIb↓
        • ⑥⑥ 治疗：血小板输注 + 抗纤溶（讲义未展开）
    • 6 功能障碍·聚集
      • Glanzmann 血小板无力症
        • ①① 病因：常染色体隐性（AR）遗传
        • ②② 发病机制：GpIIb/IIIa 缺失
        • ③③ 病理生理：血小板不能通过纤维蛋白原桥（fibrinogen bridge）互相连接
        • ④④ 并发症：黏膜出血，血小板计数与形态正常
        • ⑤⑤ 诊断：瑞斯托霉素可聚集、但加 ADP 不聚集；流式 GpIIb/IIIa↓
        • ⑥⑥ 治疗：血小板输注、抗纤溶、必要时重组因子 VIIa（讲义未展开）
    • 7 功能障碍·释放
      • 尿毒症性血小板功能障碍 UPD
        • ①① 病因：急性肾损伤（AKI）或慢性肾脏病（CKD）→ 尿毒症毒素（uremic toxins）↑
        • ②② 发病机制：vWF 与 GpIb 结合↓、GpIIb/IIIa 活性↓、ADP 与 TXA2 释放↓（三环节同时累及）
        • ③③ 病理生理：见②机制链
        • ④④ 并发症：出血倾向，血小板计数正常
        • ⑤⑤ 诊断：肾病病史 + 出血时间延长；去氨加压素（DDAVP）后出血改善支持诊断
        • ⑥⑥ 治疗：透析为一线（清除毒素）；DDAVP 用于急性出血或术前；观察出血是否改善
  • 二、典型表现
    • 表浅出血 Superficial Bleeding（Hallmark Sign）
      • ›机制：血小板减少或功能障碍 → 血小板栓形成能力↓ → 凝血块形成↓ → 血液外渗（extravasation）至周围软组织
      • 皮肤：瘀点／紫癜（petechiae／purpura）——不褪色（non-blanching）的红／紫色斑点
      • 黏膜：牙龈出血（gingival bleeding）、鼻出血（epistaxis）
      • 妇科：月经过多（menorrhagia）
      • ›阈值：血小板 <50k → 表浅出血；血小板 <10k → 严重出血（消化道出血 GIB、颅内出血 ICH）
      • ›对照：血小板病 → 表浅出血；凝血因子病 → 深部出血（关节积血、肌肉血肿）
      • 配图：瘀点与紫癜（petechiae vs purpura）、牙龈出血（gingival bleeding）、四类表现总图
  • 三、整体诊断
    • A. 识别类型 Identify the Type
      • 适应证表浅出血（superficial bleeding）
      • ›血常规（CBC）：血小板 <150k → 血小板减少；计数正常但表浅出血 → 血小板功能障碍
    • B. 评估血小板减少的原因
      • 1 血常规 + 外周血涂片 CBC and Peripheral Blood Smear
        • 适应证血小板减少
        • ›血常规三种组合：贫血 + 血小板减少 → DIC／HUS／TTP／脾扣押／APLS
        • ›单纯血小板减少 → ITP／HIT
        • ›全血细胞减少 → 再障／MDS／白血病
        • ›涂片正常 → ITP／HIT／APLS／脾扣押
        • ›血小板聚集（clumping）→ 假性血小板减少（pseudothrombocytopenia）：EDTA 所致 → 换枸橼酸盐管复测 → 恢复正常即可诊断
        • ›破碎红细胞（schistocytes）→ DIC／HUS／TTP；伴 LDH↑、结合珠蛋白↓、胆红素↑ 提示溶血
        • ›原始细胞（blasts）↑ → 白血病
        • ›假性 Pelger-Huët 中性粒细胞↑ → MDS
      • 2 骨髓活检 Bone Marrow Biopsy
        • 适应证全血细胞减少 + 涂片异常（如原始细胞）
        • ›低增生 → 再障；高增生且 blasts >20% → 白血病；高增生且发育异常、blasts <20% → MDS
      • 3 凝血检查 Coagulation Studies
        • 适应证怀疑 MAHA（溶血性贫血 + 血小板减少 + 破碎红细胞）
        • DIC：PT／INR↑、PTT↑、D-二聚体↑、纤维蛋白原↓
        • HUS／TTP：凝血检查正常
      • 4 病史与体格检查 History and Physical
        • 适应证任何血小板减少
        • ›静脉穿刺点渗血 → DIC
        • ›腹泻病后 AKI → HUS
        • ›AKI + 神经系统症状 → TTP
        • ›SLE + 反复流产 + 反复动静脉血栓 → APLS
        • ›肝素暴露 + 皮肤坏死或 4T↑ → HIT
        • ›脾大 + 肝硬化 → 脾扣押
    • C. 确定性病因 Definitive Cause
      • ›PF4 抗体 → HIT；阳性后用 5-羟色胺释放试验确认
      • ›抗磷脂抗体 → APLS（抗心磷脂、狼疮抗凝物、抗 β2 糖蛋白）
      • ›ADAMTS13 → TTP（降低）
      • ›排除继发性 ITP：SLE、HIV／HCV、恶性肿瘤、药物全阴 → 原发性 ITP
      • 排除的入口条件：孤立性血小板减少 + 涂片正常 + 凝血正常 + 无相关病史
    • D. 功能障碍评估 Type of Platelet Dysfunction
      • 1 涂片 + 出血时间 Blood Smear and Bleeding Time
        • 适应证血小板计数正常 + 表浅出血
        • ›巨大血小板 → BSS；血小板正常 → vWD／Glanzmann／UPD；出血时间延长 → 四者皆可
      • 2 病史与查体
        • ›出血家族史 → vWD／BSS／Glanzmann；重度 AKI／CKD → UPD；DDAVP 试验改善支持 UPD
      • 3 瑞斯托霉素辅因子试验 Ristocetin Cofactor Assay
        • 适应证怀疑 vWD／BSS／Glanzmann
        • ›聚集下降 → vWD 或 BSS；加血浆后恢复 → vWD，不恢复 → BSS
        • ›加 ADP 聚集 → vWD 与 BSS；不聚集 → Glanzmann
      • 4 确证检查 Confirmation
        • ›vWF 抗原 + 因子 VIII↓ → vWD；流式 GpIb↓ → BSS；流式 GpIIb/IIIa↓ → Glanzmann
