凝血病 Coagulopathy

  • 一、病理生理分型
    • A 内在途径活性下降（↑PTT）
      • ›机制链：↓Coagulation factors in intrinsic pathway → ↓XII、XI、IX、VIII → ↓Activation of common pathway → ↓Fibrin formation → ↓Thrombus formation → ↑Bleeding
      • ›中文：内在途径因子（XII、XI、IX、VIII）减少 → 共同途径激活减少 → 纤维蛋白形成减少 → 血栓形成减少 → 出血增加
      • 化验原理：PTT 试剂含硅土（silica），带负电激活因子 XII，测的是内在途径＋共同途径
      • 对应疾病：血友病 A（VIII）、血友病 B（IX）、vWD（vWF 与 VIII）、肝素性凝血病、获得性抑制物
    • B 外在途径活性下降（↑PT/INR）
      • ›机制链：↓Coagulation factors in extrinsic pathway → ↓VII → ↓Activation of common pathway → ↓Fibrin formation → ↓Thrombus formation → ↑Bleeding
      • ›中文：外在途径的启动因子 VII 减少 → 共同途径激活减少 → 纤维蛋白减少 → 出血
      • 化验原理：PT 试剂含组织凝血活酶（thromboplastin＝组织因子＋磷脂），测的是外在途径＋共同途径
      • 关键生理：因子 VII 半衰期最短（约 4–6 小时），所以肝病、维生素 K 缺乏、华法林最先打 PT
    • C 双途径同时下降（↑PT/INR 且 ↑PTT）
      • ›机制链：↓XII、XI、IX、VIII、VII → ↓Activation of common pathway → ↓Fibrin formation → ↓Thrombus formation → ↑Bleeding
      • ›中文：两条途径的因子同时减少，或共同途径因子（X、V、II、纤维蛋白原）缺乏 → 两者都延长
      • 三种解释：共同途径因子缺乏；多个因子同时不足（肝病、维生素 K 缺乏、DIC、大量输血）；存在抑制物
      • 对应疾病：DIC、肝硬化、重度维生素 K 缺乏
    • D 三条途径的快速对照
      • ›仅 PTT 延长 → 内在途径：血友病、vWD、肝素
      • ›仅 PT/INR 延长 → 外在途径：维生素 K 缺乏、因子 VII 缺乏
      • ›两者都延长 → 共同途径／多因子：DIC、肝硬化、重度维生素 K 缺乏
      • 提示内在／外在是实验室分类，体内凝血由组织因子启动
      • 提示因子 XII 缺乏 PTT 很长却几乎不出血，别一律当血友病
    • 1 内在途径缺陷
      • 血友病 A Hemophilia A
        • ①① 病因：X 连锁隐性遗传；只累及男性；占血友病的 80%；问个人／家族出血史
        • ②② 发病机制：因子 VIII 缺乏 → 内在途径受阻 → 纤维蛋白网织不出
        • ③③ 临床表现：深部出血——自发性关节积血、肌肉血肿、拔牙后迟发渗血；无瘀点
        • ④④ 诊断：PTT 延长、PT 正常；混合试验可纠正 → 因子 VIII 活性降低
        • ⑤⑤ 治疗：小量出血用 DDAVP；大出血／大手术用因子 VIII 浓缩物；反复出血或 VIII<1% 用 emicizumab
        • 监测Bethesda 滴度；滴度高 → 重组因子 VIIa 旁路
        • 要点重型（VIII<1%）无库存，DDAVP 无效，必须直接补浓缩物
      • 血友病 B Hemophilia B
        • ①① 病因：X 连锁隐性遗传；男性；占血友病的 20%
        • ②② 发病机制：因子 IX 缺乏 → 内在途径受阻
        • ③③ 临床表现：与血友病 A 相同的深部出血
        • ④④ 诊断：PTT 延长、PT 正常；混合试验纠正 → 因子 IX 活性降低
        • ⑤⑤ 治疗：因子 IX 浓缩物；手术前后预防性输注
        • 要点血友病 B 不用 DDAVP（DDAVP 不释放 IX）
      • 血管性血友病 vWD（1 型与 3 型）
        • ①① 病因：1 型最常见、常染色体显性；3 型罕见、常染色体隐性
        • ②② 发病机制：vWF 减少或缺失 → 血小板黏不住；vWF 是因子 VIII 的载体 → VIII 也被降解
        • ③③ 临床表现：黏膜表浅出血（鼻衄、牙龈、月经过多）＋ 深部出血；PTT 可延长
        • ④④ 诊断：瑞斯托霉素辅因子试验不聚集、加血浆能恢复；vWF 抗原与因子 VIII 降低
        • ⑤⑤ 治疗：小量出血用 DDAVP；大出血／大手术用 vWF 浓缩物
        • 监测止血后复查 vWF 活性（瑞斯托霉素辅因子试验）与因子 VIII
        • 提示避免任何抗血小板药（阿司匹林、NSAIDs）
      • 肝素性凝血病 Heparin Coagulopathy
        • ①① 病因：使用肝素；普通肝素 UFH 强于低分子肝素 LMWH
        • ②② 发病机制：肝素激活抗凝血酶 III（AT-III）→ 抑制因子 Xa、IXa 与凝血酶 → PTT 延长
        • ③③ 临床表现：出血倾向；PTT 延长、PT 正常；与 HIT（血小板减少＋血栓）完全不同
        • ④④ 诊断：问肝素使用史；PTT 延长、混合试验不纠正（抑制物型）
        • ⑤⑤ 治疗：鱼精蛋白硫酸盐中和肝素 → 形成无活性复合物
        • 监测观察出血改善；复查 PTT；鱼精蛋白过量本身有抗凝作用
      • 获得性凝血因子抑制物 Acquired Factor Inhibitor
        • ①① 病因：血友病 A 治疗、产后、SLE、恶性肿瘤；最常见为抗因子 VIII 抗体
        • ②② 发病机制：自身抗体中和因子 VIII → 蛋白数量在、活性没了
        • ③③ 临床表现：与血友病 A 一模一样的深部出血，但无家族史、不限男性
        • ④④ 诊断：PTT 延长且混合试验不纠正；Bethesda 滴度定量
        • ⑤⑤ 治疗：旁路制剂（重组因子 VIIa 或 aPCC）；高滴度时补因子会被中和
        • 要点无家族史＋突发深部出血＋中老年或产后女性 → 首先想它
    • 2 外在途径缺陷
      • 轻至中度维生素 K 缺乏 Mild-Moderate Vitamin K Deficiency
        • ①① 病因：摄入减少（新生儿风险最高，需预防性补充）；脂肪吸收不良（乳糜泻、克罗恩、EPI、胆道梗阻）；长期抗生素；肝硬化与华法林
        • ②② 发病机制：维生素 K 减少 → 肝内合成因子 II、VII、IX、X 减少；VII 半衰期最短 → 先掉
        • ③③ 临床表现：只有 PT/INR 延长，PTT 正常；出血倾向轻
        • ④④ 诊断：PT/INR 延长、PTT 正常；补维生素 K 后 PT/INR 改善
        • ⑤⑤ 治疗：口服或静注维生素 K；活动性出血需 PCC 或 FFP 立即补因子
        • 要点华法林抑制 VKOR，是“维生素 K 用不了”，不是“缺维生素 K”
      • 因子 VII 缺乏 Factor VII Deficiency
        • ①① 病因：常染色体隐性遗传
        • ②② 发病机制：因子 VII 显著减少 → 外在途径阻断（最短的一条断链）
        • ③③ 临床表现：孤立性 PT/INR 延长，PTT 完全正常
        • ④④ 诊断：PT/INR 延长、PTT 正常；补维生素 K 不纠正 → 确诊因子 VII 缺乏
        • ⑤⑤ 治疗：因子 VII 浓缩物；手术前后预防
        • 监测复查 PT/INR 判断疗效
    • 3 双途径缺陷
      • 弥散性血管内凝血 DIC
        • ①① 病因：脓毒症、创伤、胎盘早剥、急性髓系白血病的 APL 亚型
        • ②② 发病机制：促凝物质暴增 → 全身微血栓 → 消耗血小板、纤维蛋白原与两条途径的凝血因子 → 出血；微血栓剪切红细胞 → 破碎红细胞
        • ③③ 临床表现：器官缺血（AKI、肝衰、ARDS、脑病）＋ 表浅与深部出血；静脉穿刺点渗血是题眼
        • ④④ 诊断：PT/INR↑、PTT↑、纤维蛋白原↓、血小板↓、D-二聚体↑、破碎红细胞（＋）、因子 VIII↓
        • ⑤⑤ 治疗：治原发病第一；红细胞按 Hgb、血小板按阈值、FFP 用于 INR>1.6、冷沉淀用于纤维蛋白原<100 mg/dL
      • 肝硬化 Cirrhosis
        • ①① 病因：酒精滥用、病毒性肝炎、自身免疫性肝炎、非酒精性脂肪性肝病
        • ②② 发病机制：肝合成纤维蛋白原与内外途径因子（因子 VIII 除外）减少；TPO 减少 ＋ 门脉高压脾大 → 血小板低
        • ③③ 临床表现：PT/PTT 双延长、纤维蛋白原低、血小板低；肝病体征、转氨酶升高
        • ④④ 诊断：D-二聚体正常、破碎红细胞（−）、因子 VIII 正常或升高；与 DIC 三项对照
        • ⑤⑤ 治疗：按缺什么补什么（红细胞、血小板、FFP、冷沉淀）；维生素 K 试验不改善
        • 要点唯独因子 VIII 不低，是区分 DIC 的关键
      • 重度维生素 K 缺乏 Severe Vitamin K Deficiency
        • ①① 病因：维生素 K 极度缺乏（摄入不足＋吸收障碍长期叠加）
        • ②② 发病机制：因子 II、VII、IX、X 严重不足 → 内外两条途径都受累
        • ③③ 临床表现：PT/INR 与 PTT 同时延长；出血倾向明显
        • ④④ 诊断：双延长但纤维蛋白原正常、D-二聚体不高、无破碎红细胞
        • ⑤⑤ 治疗：PCC 或 FFP ＋ 静注维生素 K 10 mg
  • 二、典型表现
    • 1 机制与定位
      • ①① 机制链：↓Coagulation factors → ↓Ability to form thrombus → ↓Clot formation（二次止血失败）→ 血液外渗至深部组织
      • ②② 要点：纤维蛋白网失败，所以皮肤不出现针尖样瘀点，而在关节腔、肌肉筋膜腔、腹膜后持续渗血
      • ③③ 对照：血小板病 → 表浅出血（瘀点、紫癜、黏膜）；凝血病 → 深部出血（关节、肌肉、体腔、颅内）
      • ④④ 提示：深部出血表面无瘀斑，只表现为胀痛、血红蛋白下降、低血压 → 要主动去找
      • ⑤⑤ 要点：髂腰肌血肿压迫股神经 → 大腿痛、髋不能伸直、膝反射减弱，易误当拉伤
    • 2 关节与颅内（最典型、最危险）
      • 关节积血 Hemarthrosis
        • ①① 表现：关节肿胀、疼痛、活动受限、局部发热；抽出暗红色血性滑液
        • ②② 机制：滑膜血管丰富＋反复微创伤＋关节腔封闭 → 血出不去
        • ③③ 并发症：反复积血 → 含铁血黄素沉积 → 靶关节（target joint）、慢性血友病关节病
        • ④④ 治疗：尽快补因子、制动冷敷、必要时抽液减压
      • 颅内出血 ICH
        • ①① 表现：突发头痛、呕吐、意识改变、新发神经体征
        • ②② 机制：颅腔封闭无余量，血一多即压迫脑组织、升高颅内压
        • ③③ 要点：凝血病患者 ICH 死亡率远高于常人；补因子要抢在影像之前
        • ④④ 关联：有 ICH 或神经外科手术时，血小板输注阈值提高到 100k
    • 3 皮下与术后渗血
      • 瘀斑 Ecchymosis
        • ①① 表现：大片、边界不清、可隆起的皮下出血；英文也写 bruising
        • ②② 对照：瘀斑是“一片”（偏凝血病），瘀点是“一点”（偏血小板病）
        • ③③ 问诊：磕一下就一大片 vs 没磕也出——前者偏凝血病，后者偏血小板病
      • 术后或创伤后持续渗血 Prolonged Bleeding
        • ①① 表现：拔牙后渗血不止、术后引流持续血性、小伤口久压不止
        • ②② 机制：血小板栓勉强形成，纤维蛋白网始终没凝牢 → 迟发性出血
        • ③③ 提示：术前问“拔牙后有没有出血很久”比查 PT/PTT 更灵敏
    • 4 消化道出血
      • 消化道出血 UGIB / LGIB
        • ①① 表现：上消化道出血（UGIB）→ 呕血、黑便；下消化道出血（LGIB）→ 便血
        • ②② 机制：消化道是“外面看不见的深部”，凝血病患者往往量大、反复、难自止
        • ③③ 治疗：禁食、抑酸、必要时内镜，同时纠正凝血因子；单靠内镜常失败
  • 三、整体诊断
    • 1 分型：先分血小板病与凝血病
      • 诊断第一步：CBC + PT/INR + PTT
        • ①① 适应症：任何出血患者，必须先分血小板病还是凝血病
        • ②② 血小板病：血小板 <150k → 血小板减少；血小板正常且 PT/PTT 正常 → 血小板功能障碍
        • ③③ 凝血病：PT 或 PTT 升高 → 进入分型
        • ④④ 分型：仅 PTT 延长 → 内在途径；仅 PT/INR 延长 → 外在途径；两者都长 → 双途径
        • ⑤⑤ 提示：讲义把“PTT 升高、PT 正常”写了两遍，第二条应为“PT/INR 升高、PTT 正常”
    • 2 病因学检查
      • 诊断第二步：混合试验 + 病史查体
        • ①① 适应症：PTT 延长而 PT/INR 正常
        • ②② 结果一：PTT 被纠正 → 因子缺乏 → 有家族史者考虑 vWD 或血友病
        • ③③ 结果二：PTT 不被纠正 → 存在抑制物 → 用过肝素＝肝素性凝血病
        • ④④ 结果三：无抗凝药但有产后／SLE／肿瘤 → 因子 VIII 抑制物 → 查 Bethesda 滴度
        • ⑤⑤ 要点：纠正＝缺因子；不纠正＝有抑制物
      • 诊断第三步：因子活性与瑞斯托霉素试验
        • ①① 适应症：混合试验可纠正者
        • ②② 结果：因子 VIII 活性↓ → 血友病 A；因子 IX 活性↓ → 血友病 B
        • ③③ 结果：vWF 水平↓ 且瑞斯托霉素辅因子试验↓ → vWD
        • ④④ 提示：vWD 的 vWF 少了，携带的因子 VIII 也跟着低
    • 3 维生素 K 试验与双途径鉴别
      • 诊断第四步：维生素 K 试验性治疗
        • ①① 适应症：PT/INR 延长而 PTT 正常；或两者都延长
        • ②② 结果：补维生素 K 后改善 → 维生素 K 缺乏（最常见原因是华法林）
        • ③③ 结果：不改善且只有 PT 长 → 因子 VII 缺乏（伴家族史）
        • ④④ 结果：不改善且两者都长 → DIC（穿刺点渗血）或肝硬化（肝病体征、转氨酶升高）
      • 诊断第五步：DIC 组合 + 涂片 + 因子 VIII
        • ①① 适应症：PT 与 PTT 都延长且维生素 K 试验不纠正
        • ②② DIC：破碎红细胞（＋）、纤维蛋白原↓、D-二聚体↑、因子 VIII↓
        • ③③ 肝硬化：破碎红细胞（−）、纤维蛋白原↓、D-二聚体正常、因子 VIII 正常
        • ④④ 要点：这三项是 DIC 与肝硬化的分水岭
  • 四、整体治疗
    • 血制品选择与监测（任何凝血病通用）
      • 浓缩红细胞 PRBCs：按血红蛋白阈值（7／8／10）输注，改善贫血
      • 血小板：按血小板阈值（100k／50k／10k）输注
      • 新鲜冰冻血浆 FFP：活动性出血、侵入性操作前、INR>1.6 且 PTT 延长
      • 冷沉淀：纤维蛋白原 <100 mg/dL 时使用
      • 监测血常规看 Hgb 与血小板；FFP 看 PT/PTT；冷沉淀看纤维蛋白原
