大细胞性贫血 Macrocytic Anemia

  • 一、总论与分类
    • 巨幼细胞性贫血 Megaloblastic Anemia
      • ①① 核心机制：↓DNA 合成 → 红细胞前体细胞核成熟落后于胞质 → 产生巨幼红细胞（megaloblasts）
      • ①① 结果：巨幼红细胞在骨髓／脾被吞噬，并发生凋亡 → 贫血
      • ②② ↓B12 的链条：↓甲硫氨酸合酶（methionine synthase）→ ↓甲基四氢叶酸转化为四氢叶酸 → ↓核苷酸合成 → ↓DNA 合成
      • ②② ↓叶酸的链条：↓二氢叶酸 → ↓四氢叶酸 → ↓核苷酸合成 → ↓DNA 合成
      • ③③ 形态学后果：↓红细胞成熟 → 大细胞（MCV >100 fL）；↓中性粒细胞成熟 → 分叶过多中性粒细胞（hypersegmented neutrophils，>5 叶）
    • 非巨幼细胞性贫血 Non-Megaloblastic Anemia
      • 机制尚不明确，但同样产生大红细胞（MCV >100 fL）
      • 四大原因：酒精、肝硬化、甲状腺功能减退、骨髓增生异常综合征 MDS
      • 要点非巨幼的涂片没有分叶过多中性粒细胞，这是与巨幼的第一分水岭
  • 二、病因
    • 维生素 B12 缺乏
      • ①① 摄入减少（少见）：酒精、严格素食
      • ①① 需求增加：妊娠（母婴都需要 B12 进行骨髓 DNA 合成）
      • ①① 吸收减少（最常见）——胃：胃切除、萎缩性胃炎（↓胃酸与内因子 IF）；恶性贫血（pernicious anemia，抗壁细胞抗体 → ↓胃酸与 IF；抗 IF 抗体 → 结合 IF）
      • ①① 吸收减少——小肠：克罗恩病、乳糜泻、回肠切除（失去 IF-B12 复合物的转运上皮）；鱼绦虫（fish tapeworm）与细菌过度生长（在肠腔代谢 B12）
      • ①① 吸收减少——胰腺：胰腺功能不全 → ↓胰蛋白酶 → 不能降解 haptocorrin → B12 无法与 IF 结合
      • ③③ 恶性贫血常伴其他自身免疫病：桥本甲状腺炎、白癜风
    • 叶酸缺乏
      • ①① 摄入减少（最常见）：酒精
      • ①① 吸收减少——小肠：克罗恩病、乳糜泻（丢失转运 folate 的肠上皮）
      • ①① 吸收减少——药物：酒精（↓叶酸从肠上皮进入血液）、苯妥英（phenytoin，↓肠内结合酶 conjugase，多谷氨酸不能转成单谷氨酸）
      • ①① 需求增加：妊娠与慢性溶血（骨髓造血需求增加）
      • ①① 代谢受阻：甲氨蝶呤（methotrexate）与 TMP-SMX 抑制二氢叶酸还原酶 → ↓四氢叶酸 → ↓DNA 合成；此时叶酸存在但无法利用，可用亚叶酸钙（folinic acid）解救
  • 三、临床表现与并发症
    • 三、临床表现
      • 经典三联
        • ①① 苍白：结膜、黏膜、掌纹苍白（↓氧输送到组织）
        • ②② 乏力、呼吸困难、心绞痛：组织缺血；合并冠心病时心肌缺血加重
        • ③③ 高动力状态：脉压增大、心动过速、收缩期血流杂音、严重者高输出量心衰
      • 与其他贫血相同之处
        • 表现取决于贫血发生速度与程度，而非 MCV 大小
        • 要点大细胞贫血的病人，神经系统症状是"额外"的线索，指向 B12
    • 四、并发症
      • B12 缺乏的神经系统并发症
        • ①① 机制：↓B12 → 甲基丙二酰辅酶 A（methyl malonyl CoA）不能转成琥珀酰辅酶 A → 堆积 → 脊髓与周围神经轴索脱髓鞘
        • ③③ 亚急性联合变性（subacute combined degeneration）：脊髓小脑束脱髓鞘 → 共济失调；皮质脊髓侧束脱髓鞘 → 痉挛性瘫痪；后柱脱髓鞘 → 位置觉与振动觉丧失
        • ③③ 周围神经病：四肢远端感觉异常
        • ③③ 神经精神症状：痴呆（任何痴呆都要查 B12）
      • B12 缺乏的心血管并发症
        • ①① 机制：↓B12 → 同型半胱氨酸（homocysteine）不能转成甲硫氨酸 → 血同型半胱氨酸↑ → 促炎细胞因子与血小板聚集↑ → 内皮功能障碍 → 动脉粥样硬化斑块与血栓 → 动脉粥样硬化性心血管病（ASCVD）
        • ③③ 表现：冠心病、外周动脉疾病、脑血管病风险↑
      • 叶酸缺乏的并发症
        • ›心血管：↑同型半胱氨酸 → 内皮功能障碍 → ASCVD（机制同 B12）
        • ›产科：↓叶酸 → 前后神经孔闭合延迟 → 神经管缺陷（neural tube defects）
        • 神经管缺陷四型：无脑儿（anencephaly，脑与颅骨大部缺失）、隐性脊柱裂（spina bifida occulta，椎板未融合）、脑膜膨出（meningocele，仅脑膜膨出）、脊髓脊膜膨出（myelomeningocele，脑膜与脊髓都膨出）
  • 四、诊断与治疗
    • 五、诊断路径
      • 第一步：血常规 + 网织红指数
        • 适应证：怀疑贫血（苍白、乏力、呼吸困难、高动力状态）
        • 贫血：Hgb <13 g/dL（男）、<12 g/dL（女）
        • 大细胞性贫血：MCV >100 fL
        • ›网织红指数 <2% → 生成不足（再障与慢性病贫血属于此类）
      • 第二步：外周血涂片分巨幼与非巨幼
        • 巨幼细胞性：分叶过多中性粒细胞（>5 叶）
        • 非巨幼细胞性：没有分叶过多中性粒细胞，需查四大原因——酒精（问饮酒史，戒酒后恢复）、肝硬化（查肝功能）、甲减（查 TSH）、MDS（全血细胞减少时做骨髓活检）
      • 第三步：B12 与叶酸水平
        • B12 缺乏：↓B12、↑甲基丙二酸（MMA）、↑同型半胱氨酸
        • 叶酸缺乏：↓叶酸（红细胞叶酸更准确）、MMA 正常、↑同型半胱氨酸
        • 要点MMA 只随 B12 缺乏升高，是与叶酸缺乏最关键的分水岭
      • 第四步：边界值的处理
        • 适用：巨幼细胞性大细胞贫血而 B12 与叶酸处于临界值
        • 查 MMA 与同型半胱氨酸确定，二者都高支持 B12；仅同型半胱氨酸高支持叶酸
      • 第五步：找 B12 缺乏的原因
        • 抗壁细胞抗体与抗内因子抗体：阳性支持恶性贫血
        • ›Schilling 试验（用于没有抗体的 B12 缺乏）：尿中 B12 正常 → 摄入不足或需求增加；尿中 B12↓ → 吸收不良，再进一步定位吸收障碍部位
    • 六、治疗
      • 急性处理：输注浓缩红细胞 PRBCs
        • 适应证：Hgb <7 g/dL 且稳定；Hgb <8 g/dL 且有冠心病；Hgb <10 g/dL 且有急性心梗；急性贫血伴血流动力学不稳
        • 目的：↑氧输送、↓组织缺血
        • 监测输血过程中密切监测血红蛋白／红细胞压积，看是否达标或继续下降
      • B12 缺乏的治疗
        • 口服 B12：用于摄入不足（饮食性）与需求增加（妊娠）
        • 肌注 B12：用于重度缺乏（有症状贫血 + 神经症状）与吸收不良（恶性贫血、胃切除、回肠切除、乳糜泻、克罗恩病）
        • ›目的：恢复 B12 → ↑红细胞生成并防止脱髓鞘继续进展
        • 监测血常规与 MCV 应恢复正常；网织红细胞应上升；B12 水平应恢复；神经症状在数周至数月内改善（严重者可能不完全恢复）
      • 叶酸缺乏的治疗
        • 口服叶酸：所有情况的一线（即使存在吸收不良）
        • 肠外叶酸：仅用于重度缺乏（有症状贫血），不常用
        • ›目的：恢复叶酸 → ↑红细胞生成；妊娠期可预防神经管缺陷
        • 监测MCV 恢复、网织红细胞上升、血清叶酸或红细胞叶酸恢复
        • 提示单用叶酸治疗大细胞贫血可掩盖 B12 缺乏 → 使神经系统症状加重，因此必须同时评估 B12
