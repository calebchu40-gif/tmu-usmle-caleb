微细胞性贫血 Microcytic Anemia

  • 一、总论与分类
    • 病理生理：两条通路
      • ①① ↓血红素合成（↓Heme synthesis）：↓Fe++ 或缺血红素合成酶 → ↓血红蛋白 → 红细胞数量与体积均下降
      • ②② ↓珠蛋白合成（↓Globin synthesis）：α 或 β 珠蛋白链不足 → ↓血红蛋白 → 小细胞
      • 要点两条通路都指向同一结果——血红蛋白不够，细胞被"造小了"
    • MCV 分类（贫血 + MCV 定类型）
      • 小细胞性：MCV <80 fL
      • 正细胞性：MCV 80–100 fL
      • 大细胞性：MCV >100 fL
    • 小细胞四因口诀 TAILS
      • T＝Thalassemia（地中海贫血）
      • A＝Anemia of chronic disease（慢性病贫血）
      • I＝Iron deficiency anemia（缺铁性贫血）
      • L＝Lead poisoning（铅中毒）
      • S＝Sideroblastic anemia（铁粒幼细胞性贫血）
      • 要点IDA 与铁粒幼细胞性贫血的 RDW↑；地中海贫血与慢性病贫血的 RDW 正常
      • 要点小细胞性贫血中除地中海贫血外，其余都是生成不足（RPI <2%）
  • 二、病因与发病机制（逐病五格）
    • 缺铁性贫血 Iron Deficiency Anemia（IDA）
      • ①① 病因：摄入不足（素食者）；吸收不良（克罗恩病 Crohn disease、乳糜泻 celiac disease、胃切除 gastrectomy、Roux-en-Y 胃旁路术）；慢性失血（月经过多、消化性溃疡、结直肠癌）；需求增加（妊娠）
      • ②② 发病机制：↓Fe++ → ↓血红素合成 → ↓血红蛋白合成 → 小细胞低色素性贫血
      • ③③ 临床表现：乏力、苍白；重症出现反甲（koilonychia）、异食癖（PICA）、不宁腿综合征（restless leg syndrome）、Plummer-Vinson 综合征
      • ④④ 诊断：↓血清铁、↓铁蛋白（ferritin）、↓转铁蛋白饱和度（TSAT）、↑总铁结合力（TIBC）；涂片小细胞低色素、RDW↑
      • ⑤⑤ 治疗：口服硫酸亚铁（ferrous sulfate）为一线，加维生素 C 促吸收；不能耐受、吸收障碍或重度者用静脉右旋糖酐铁（iron dextran）
    • 铁粒幼细胞性贫血 Sideroblastic Anemia
      • ①① 病因：遗传（X 连锁）；骨髓增生异常综合征 MDS-RARS（进展为急性髓系白血病 AML 风险↑）；维生素 B6 缺乏；药物（异烟肼 INH、利奈唑胺 linezolid、氯霉素 chloramphenicol）；酒精；铅中毒
      • ②② 发病机制：↓血红素合成酶 → 铁在线粒体内堆积 → 环形铁粒幼细胞（ringed sideroblasts）→ 无效造血 → 贫血
      • ③③ 临床表现：贫血；铅中毒时见牙龈铅线、脑病、腹绞痛、垂腕／垂足、嗜碱性点彩
      • ④④ 诊断：涂片嗜碱性点彩（basophilic stippling）与 Pappenheimer 小体；骨髓普鲁士蓝染色见环形铁粒幼细胞；铁与铁蛋白正常或↑
      • ⑤⑤ 治疗：停用致病药物与酒精；维生素 B6（吡哆醇 pyridoxine）；铅中毒用二巯丙醇（dimercaprol）或 EDTA
    • 慢性病贫血 Anemia of Chronic Disease（ACD）
      • ①① 病因：↑铁调素（hepcidin）——类风湿关节炎、系统性红斑狼疮 SLE、恶性肿瘤；↓促红细胞生成素（EPO）——慢性肾病（ESRD）
      • ②② 发病机制：↑Hepcidin → 铁被扣押在巨噬细胞、远离骨髓；↓EPO → 骨髓红细胞生成减少
      • ③③ 临床表现：轻中度贫血，更多见于正细胞范围（本章把它列为小细胞病因之一）
      • ④④ 诊断：↓血清铁、↑铁蛋白、↓TSAT、↓TIBC（与 IDA 正好相反）
      • ⑤⑤ 治疗：治原发病（免疫抑制剂／化疗）；慢性肾病且 Hgb <10 时用 EPO（用前常需静脉补铁）
    • 地中海贫血 Thalassemia
      • ①① 病因（α 型）：16 号染色体 α 等位基因缺失 1／2／3／4 个 → 静止携带者／轻型／HbH 病／Hb Bart's 胎儿水肿
      • ①① 病因（β 型）：11 号染色体启动子或剪接位点点突变 → 轻型／中间型／重型
      • ②② 发病机制：↓α 链 → ↑β 四聚体（HbH）或 ↑γ 四聚体（Hb Bart's）；↓β 链 → ↑α 四聚体聚集 → 红细胞内包涵体 → 溶血
      • ③③ 临床表现：溶血（黄疸、↑LDH、↓结合珠蛋白）、肝脾大（髓外造血）、骨骼异常（骨髓扩张）；Hb Bart's → 胎儿水肿、宫内死亡
      • ④④ 诊断：涂片靶形细胞（target cells）；血红蛋白电泳：β 地贫 ↑HbA2（>3.5%）与 ↑HbF；HbH 病 ↑HbH（可能需 DNA 分析）
      • ⑤⑤ 治疗：骨髓移植（可能治愈）；输血依赖者需去铁治疗
  • 三、临床表现与并发症
    • 经典三联 Classic Findings
      • ①① 苍白 Pallor：↓氧输送 → 黏膜、结膜、掌纹苍白
      • ②② 乏力、呼吸困难、心绞痛：组织缺血；合并冠心病（CAD）时心肌缺血加重
      • ③③ 高动力状态（hyperdynamic state）：化学感受器激活 → ↑交感神经 → ↑心率、↑每搏量 → ↑心输出量；表现为脉压增大、心动过速、收缩期血流杂音、严重者高输出量心衰
    • 缺铁性贫血的并发症
      • Koilonychia：匙状甲（反甲）
      • PICA：异食癖，嗜食泥土等非食物
      • 不宁腿综合征：夜间下肢不适、活动后缓解
      • Plummer-Vinson 综合征：食管蹼（esophageal webs）＋吞咽困难＋缺铁性贫血
    • 铅中毒（铁粒幼）的并发症
      • 牙龈铅线（lead lines）
      • 铅性脑病（encephalopathy）
      • 腹绞痛（abdominal colic）
      • 垂腕／垂足（wrist drop／foot drop）
      • 嗜碱性点彩：核糖体在红细胞内堆积所致
    • 地中海贫血的并发症
      • 溶血表现：黄疸、↑LDH、↓结合珠蛋白
      • 肝脾大：髓外造血所致
      • 骨骼异常：骨髓腔扩张所致（颅骨竖发征、地贫面容）
      • Hb Bart's：胎儿水肿、心力衰竭、肝脾大，多宫内死亡或出生后不久死亡
  • 四、诊断与治疗
    • 四、诊断路径
      • 第一步：血常规 + 网织红指数
        • 适应证：怀疑贫血（苍白、乏力、呼吸困难、高动力状态）
        • 贫血：血红蛋白 Hgb <13 g/dL（男）、<12 g/dL（女）
        • ›网织红指数（RPI）<2% → 生成不足；RPI >2% → 破坏或丢失
        • 小细胞：MCV <80 fL；IDA 与铁粒幼 RDW↑，地贫与 ACD 的 RDW 正常
      • 第二步：铁四项
        • 血清铁：IDA 与 ACD ↓；地贫与铁粒幼正常或↑
        • 铁蛋白：IDA ↓；ACD 与铁粒幼 ↑
        • 转铁蛋白饱和度 TSAT：IDA 与 ACD ↓
        • 总铁结合力 TIBC：IDA ↑、ACD ↓（与铁蛋白方向相反，是鉴别关键）
      • 第三步：外周血涂片
        • ›嗜碱性点彩、Pappenheimer 小体 → 铁粒幼细胞性贫血
        • ›靶形细胞 → 地中海贫血
      • 第四步：骨髓铁染色
        • ›环形铁粒幼细胞（普鲁士蓝染色）→ 铁粒幼细胞性贫血；环由铁在粒线体堆积而成
      • 第五步：血红蛋白电泳
        • β 地中海贫血：↑HbA2（>3.5%）与 ↑HbF
        • HbH 病：↑HbH，必要时用 DNA 分析确认 α 链缺失
    • 五、治疗与监测
      • 急性处理：输注浓缩红细胞 PRBCs
        • 适应证：Hgb <7 g/dL 且血流动力学稳定；Hgb <8 g/dL 且有冠心病；Hgb <10 g/dL 且有急性心肌梗死；急性失血伴血流动力学不稳（低血压与器官衰竭）
        • ›目的：↑红细胞 → ↑组织氧输送 → ↓组织缺血
        • 要点1 单位 PRBC 约提高血红蛋白 1 g/dL
      • 治疗原发病
        • IDA：治消化性溃疡、炎症性肠病、乳糜泻、月经过多
        • ACD：免疫抑制剂、化疗
        • 铁粒幼：停药物与酒精；铅中毒用二巯丙醇或 EDTA
        • 地贫：骨髓移植
      • 支持治疗
        • 铁剂：口服硫酸亚铁为一线（配维生素 C）；静脉右旋糖酐铁用于不耐受、吸收障碍（IBD、RYGB）、重度 IDA
        • 红细胞生成刺激剂 ESA：EPO 或达贝泊汀（darbepoetin）；用于慢性肾病贫血且 Hgb <10，目标是维持 Hgb >10
        • 维生素 B6：用于获得性 B6 缺乏（如 INH 治疗）与遗传缺陷；提高 ALA 合酶活性以增加血红蛋白合成
        • 脾切除：脾大伴血管外溶血、输血需求增加时；目的是去除溶血场所
      • 监测
        • 监测监测血常规与血红蛋白：输血后看是否达标，或持续下降（需进一步找原因）
        • 地贫与铁粒幼：监测继发性血色病（restrictive cardiomyopathy、色素沉着、糖尿病、关节痛），必要时用去铁胺（deferoxamine）
        • IDA：网织红细胞应上升；铁四项应恢复正常
